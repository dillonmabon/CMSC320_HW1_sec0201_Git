Q1: Why might we consider using Git?

Answer: We would want to use git for version control and code sharing.
When working on a group project or production team, being able to view
pull requests and approve change with commit messages if especially helpful.
This allows developers to have a local copy and clone older or newer verison of
the project/codebase.

Q2: What field could data science be applied to? Give an Example.

Answer: Data science can be applied to public health. Large public datasets of
patient health data are incredibly useful for data scientists to analyze. For
example, at NIH, data scientists use patient health data to find insights related
to variables that cause and influence cancer.


Q3: What is the difference between Merging and Rebasing?

Answer: Merging combines two versions under a new merge commit, while rebasing
puts one of the changes after the other. So merging shows when two files were
edited at the same time, while rebasing makes it look like one happened the other.
